Projects and sessions

Your folders, with terminals beside them.

Open a folder as a project group, then add a terminal or a Codex tile. Each starts only when you press Start and keeps running while you move around the canvas.

When a session rings the bell or exits, its tile gets an amber ring and a Waiting for you strip. Ctrl+J lists everything waiting.

Terminal and Codex tiles run on Linux today.

Tasks

Tasks

Turn a note into work for Codex.

Make a note a task and assign it to a Codex tile. Send pastes the text into that terminal without pressing Enter, so you submit it yourself.

Task status only reports facts: when the text was sent, and whether you edited it afterwards.

Get the app

Get the app

Pre-release builds are on GitHub.

A native desktop build with the Rust runtime bundled in. No account and no server. Canvases stay in SQLite on your disk.

The canvas runs on Linux, macOS, and Windows. Terminal and Codex tiles need Linux for now. MIT licensed.
