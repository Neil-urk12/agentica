# Rust backend dependency notices

Inventory for the resolved `agentica-runtime` dependency graph in `Cargo.lock`,
including build tools and dependencies conditional on the target platform. Not
all entries are linked into every executable. Sources are the exact published
crate versions below, pinned by archive SHA-256. Dependency sources are unmodified.

Distribution locations are the locally built `target/release/agentica-backend`
and the linked runtime in `target/release/agentica-desktop` (Windows uses `.exe`).
Keep applicable license and copyright notices with distributed binaries. This
inventory covers the Rust runtime; frontend and Tauri distribution inventories
must also be checked when producing installers.

Generated from `cargo tree --locked -p agentica-runtime --target all`. Full upstream
license and NOTICE texts follow; duplicate texts are included once. Copyright
and attribution obligations remain in those texts. For the optional UEFI target
crate `r-efi`, use its MIT license option; its published AUTHORS file contains the
MIT text, copyright notices, and alternative-license notices.

`libsqlite3-sys` compiles the bundled SQLite 3.53.2 amalgamation into both
executables. SQLite is in the public domain and requires no notice; its source
carries the SQLite blessing instead of a license. The wasm-only crate
`rsqlite-vfs` (MIT per its manifest) publishes no license file and is not linked
into the Windows or Linux executables.
